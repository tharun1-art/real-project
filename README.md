# Currency Exchange Platform

A learning project for building and deploying a currency
exchange application using DevOps practices.

## Project Goals

- Convert INR into USD, EUR, GBP, AUD, and another currency.
- Build a frontend using React.js, HTML, CSS, and JavaScript.
- Build a backend API using Node.js.
- Build an admin panel using PHP Laravel.
- Support live exchange-rate updates using WebSockets.
- Practice Git, Linux, Docker, CI/CD, AWS, monitoring, and security.
